\author{Jinlin Wu}

\begin{abstract}
Urban functional ruptures---loss of services, safety, and connectivity---do not only appear in static maps; they reshape how people move. Yet most urban diagnosis relies on outcome indicators (e.g., vacancy or crime rates) rather than on the \emph{process}: how daily route choices adapt to functional discontinuities.

We propose \textbf{behavioral reference frames} for rupture detection with \emph{spatial specificity}. Instead of using shortest paths as a baseline (a physical reference frame that humans rarely follow), we learn a \emph{behavioral} baseline from trajectories in functional cities: a generative model of ``normal'' route choice under comparable origin--destination intent and time context. Applied to a target city (Detroit), the model yields a counterfactual expectation of \emph{where} travelers should traverse. Comparing this expectation to realized mobility produces a spatial residual map---a \textbf{behavioral avoidance field}---that reveals not just the \emph{degree} of detouring but its \emph{structure}: which corridors are under-used, which alternatives are substituted, and where behavioral boundaries emerge.

To make the reference usable, we build a geo-explicit representation that aligns large-scale trajectories (WorldTrace) with multi-source urban context on a shared Detroit grid, including (i) an OpenStreetMap-derived road-proximity field used as a \emph{soft} prior, (ii) functional semantics from SafeGraph points of interest (POI), and (iii) built-environment appearance from ArcGIS Wayback imagery. We adopt a decision--execution decomposition with an autoregressive waypoint planner to avoid a common collapse in end-to-end generators (overly direct routes), so the model can represent corridor-level decisions that define normal route choice. Robustness is supported by adaptive resampling and trajectory masking, and diffusion is treated as a gated extension for multi-modal intent once a valid single-mode baseline is established.
\end{abstract}
