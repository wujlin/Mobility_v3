We presented a behavioral-reference perspective on urban functional rupture: mobility traces can reveal where everyday route choice deviates from a learned ``normal'' baseline. We proposed a cross-city transfer design to construct this behavioral reference frame and to turn prediction mismatches into spatial rupture signatures. Methodologically, we built a geo-explicit representation (soft map priors, POI semantics, overhead imagery) and adopted decision-consistent planning to avoid overly direct baselines that would collapse toward shortest paths.

Future work will expand the reference city set, strengthen external validation (e.g., vacancy, safety, service accessibility proxies), and explore richer semantic representations (land use and remote sensing) to improve corridor discrimination near destinations. Once a stable single-mode reference is established, multi-modal diffusion can be used to model alternative \emph{normal} route-choice patterns without compromising interpretability.
