We presented a leakage-free, dt-fixed benchmark for OD-conditioned trajectory generation and demonstrated a key limitation of pure diffusion models: \emph{macroscopic shrinkage}, where samples improve best-of-$K$ coverage yet under-estimate displacement and speed. To address this, we proposed \textbf{Physics-Informed Residual Diffusion}, which anchors low-frequency scale with a frozen deterministic prior and lets diffusion model only stochastic residuals, optionally guided by a train-only navigation-field prior.

Future work should (i) incorporate road-graph constraints beyond grid representations, (ii) design adaptive mechanisms to prevent mean-flow priors from over-tethering samples, and (iii) validate stability through larger-scale, multi-seed evaluations under the same strict data contract.
