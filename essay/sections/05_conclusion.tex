We presented a leakage-free, dt-fixed benchmark for OD-conditioned trajectory generation and demonstrated a key limitation of pure diffusion models: \emph{macroscopic shrinkage}, where samples improve best-of-$K$ coverage yet under-estimate displacement and speed. To address this, we proposed \textbf{Physics-Informed Residual Diffusion}, which anchors macroscopic motion scale with a frozen deterministic prior and lets diffusion model only stochastic residuals, optionally conditioned on a train-only navigation field.

Future work should (i) incorporate road-graph constraints beyond grid representations, (ii) design adaptive mechanisms so that mean-flow conditioning signals improve coverage without overly constraining macroscopic motion, and (iii) validate stability through larger-scale, multi-seed evaluations under the same strict data contract. Ultimately, this framework provides a reliable, physics-consistent foundation for next-generation mobility Digital Twins, enabling planners to simulate diverse future scenarios without sacrificing macroscopic realism.
