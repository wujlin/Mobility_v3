\begin{abstract}
Abstract placeholder (150--250 words).
We study long-horizon \emph{route generation}: sampling realistic, feasible, and diverse paths between an origin and a destination under time and semantic context.
We propose \textbf{CascadeTraj}, a cascaded decision--execution generator that separates corridor-level commitments (sparse waypoints) from continuous physical execution.
The framework supports soft map priors (e.g., road proximity) and optional census-derived spatial covariates as semantic guidance, without relying on hard output masking.
\end{abstract}
