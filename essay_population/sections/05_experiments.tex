\label{sec:experiments}

\paragraph{E0: ground-truth corridor audit (fixed diagnostic cases).}
Before comparing models, we audit the ground-truth routes to identify OD conditions with clear corridor-level multi-modality.
We cluster GT routes within each OD bucket using simple polyline features (e.g., signed deviation, progress, and length ratios) and select a small set of high-separation cases.
All qualitative figures (Fig.~\ref{fig:mode-collapse}) and collapse metrics are computed on these \emph{fixed} cases to avoid cherry-picking; GT diversity also provides a reference scale for interpreting collapse severity.

\paragraph{Data and preprocessing.}
We evaluate on large-scale mobility traces with consistent map-matched coordinates (e.g., WorldTrace) and construct trip segments with origin--destination intent and time context.
We standardize representation to a shared coordinate system, and build optional spatial context channels (soft map priors, POI/imagery features, and census covariates when enabled).
We report split definitions and leakage controls (train/val/test) to ensure reproducibility.

\paragraph{Baselines (direct competitors).}
We include end-to-end generators that output the full coordinate sequence directly:
(i) an autoregressive coordinate model, and
(ii) an end-to-end diffusion model \citep{ho2020ddpm} conditioned on $(o,d,t_0)$ and optional context.
These baselines serve as diagnostic references for two common failure modes under topological multi-modality: destructive averaging (collapse) and corridor-level mode interference (blur).
We also include a hard-constrained variant (e.g., output masking / masked-softmax) as a \emph{diagnostic} ablation to separate ``feasibility by truncation'' from true distribution learning.

\paragraph{E1: diagnostic end-to-end baselines (collapse vs.\ interference).}
On the fixed audit cases, we compare deterministic coordinate regression (L2) and stochastic end-to-end diffusion under the same conditioning.
We report both qualitative overlays (Fig.~\ref{fig:mode-collapse}) and corridor-level metrics that quantify intra-condition diversity and corridor coverage relative to the GT corridor clustering.

\paragraph{E2: waypoint bottleneck ablation (decision vs.\ execution).}
To isolate where corridor coverage is gained or lost, we run two waypoint-based controls:
(i) a skeleton-only generator that connects the waypoint sequence into a polyline, and
(ii) a waypoint-conditioned execution model that generates residual trajectories around the skeleton.
These ablations test whether diversity is created at the decision stage or merely ``washed out'' during continuous execution.

\paragraph{E3: generative decision model (waypoint diffusion).}
To turn the decision stage into an explicit multi-modal sampler, we train a lightweight diffusion model to generate waypoint skeletons conditioned on a coarse OD intent (OD bin centers).
We evaluate corridor coverage and intra-condition diversity on the fixed audit cases, and use this decision model as the planner component of CascadeTraj.

\paragraph{E4: composed cascade (decision + execution).}
We compose the waypoint decision sampler with a waypoint-conditioned residual diffusion executor to generate full-resolution routes.
This experiment tests whether corridor coverage gained at the decision stage is preserved after continuous execution, while improving realism and feasibility.
We find that naive composition can \emph{lose} corridor coverage even when the decision stage is diverse, indicating that execution can overwrite topological commitments.
We therefore vary the execution refinement strength by scaling the residual component, which exposes a practical tradeoff between commitment preservation (corridor adherence) and geometric detail.

\paragraph{Core evidence: mode collapse visualization.}
To make the failure mode unambiguous, we include a primary qualitative figure comparing multiple samples for the same condition:
end-to-end baselines vs CascadeTraj.
The figure highlights whether samples occupy distinct corridors (good) or blur into overly direct/average routes (collapse).
This visualization is treated as Figure~1/2-level evidence rather than an appendix-only artifact.

\paragraph{Metrics: feasibility, realism, intent, and diversity.}
We report four complementary metric groups:
\begin{itemize}
  \item \textbf{Intent consistency:} endpoint error and arrival/termination consistency (reaching the destination without drift).
  \item \textbf{Feasibility proxies:} on-road/off-road ratios computed against map proxies, with sensitivity audits over dilation/buffering to avoid proxy-hole artifacts.
  \item \textbf{Realism:} path-shape similarity metrics (e.g., DTW/Fr\'echet-style distances) and length/detour statistics to capture geometric fidelity beyond endpoint error.
  \item \textbf{Diversity/coverage:} corridor-level coverage metrics (e.g., distinct corridor clusters per condition), and distributional diversity scores (e.g., self-BLEU on discretized route tokens) to distinguish ``one good path'' from ``many plausible alternatives''.
\end{itemize}

\paragraph{Ablations (tying design to failure modes).}
We design ablations to map each architectural choice to a specific failure mode:
\begin{itemize}
  \item \textbf{No decision stage:} remove waypoint commitment to test whether collapse returns.
  \item \textbf{No soft map prior:} test feasibility degradation without hard truncation.
  \item \textbf{No semantic context:} remove POI/imagery channels to test corridor-choice realism.
  \item \textbf{Optional census guidance:} enable census covariates only as an ablation to quantify controllability/extensibility without shifting the paper's focus to population synthesis.
\end{itemize}

\paragraph{Failure analysis.}
We explicitly report characteristic degeneracies: overly direct routes, corridor collapse, and off-road artifacts.
For each, we show which component (decision stage, execution stage, or soft priors) mitigates the issue and where limitations remain.
